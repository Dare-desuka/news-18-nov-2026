## The image

`entry.png` (1024×1024) is a newspaper front page drawn with Python and
Pillow from the day's reporting:

- **Shenzhen — Diplomacy.** Xi Jinping greets Donald Trump on the tarmac
  as APEC opens; Xi and Vladimir Putin met ahead of Thursday's three-way
  talks.
- **The Gulf — Conflict.** US jets struck a Revolutionary Guard missile
  site on Qeshm Island; Iran fired drones at Bahrain and Kuwait, targeting
  US forces.
- **Ukraine — War.** Ukraine struck the Kerch Bridge to Crimea for a second
  day; part of the road span fell into the strait.
- **Alaska — US Politics.** Democrat Mary Peltola beat Senator Dan Sullivan;
  Democrats are projected at 56–44 in the Senate.
- **Also today.** Cyclone Akvan nears India's Andhra coast; Ebola in DR Congo
  passes 11,000 cases; the US loses its measles-free status after 26 years.

Sources as reported on the day: AP, Reuters, AFP, Al Jazeera.

## The program

`main.py` (Python 3.13, standard library only) copies `entry.png` to
`/output/entry.png`. It writes the same bytes on every run.

Run it locally:

```
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```
